# MeshBridge Alpha

MeshBridge Alpha is an experimental, least-privilege Home Assistant App wrapper
for the Meshtastic® `meshtasticd` Alpha Alpine daemon. Its immutable upstream
pin and GPL notice are recorded in the repository-level
[upstream.yaml](../upstream.yaml) and [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

MeshBridge is independent and not affiliated with Meshtastic LLC or the
Meshtastic project. No warranty is provided - use at your own risk.
